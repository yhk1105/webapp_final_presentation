Blackjack 模擬訓練系統

基於蒙地卡羅模擬的 21 點策略學習平台

Web APP 開發 - 期末專案
第十組

專案簡介

  • 基於 Web app 開發的 21 點訓練平台
  • 幫助玩家學習基本策略並提升決策能力
  • 使用蒙地卡羅模擬提供即時建議與勝率分析
  • 提供使用者決策分析

核心功能

  • 🎮 互動式遊戲介面
  • 🤖 基於蒙地卡羅模擬的建議系統
  • 📊 決策錯誤追蹤與檢討
  • 📈 牌靴狀態監控
  • 🃏 多副牌（1-8副）支援

系統架構

前端 ↔ API Gateway ↔ 核心邏輯 ↔ DB

API 設計：遊戲核心

API Endpoints

  • POST /api/games
    建立新遊戲（設定牌組數）
  • POST /api/games/{id}/action
    執行動作（Hit, Stand, Double）
  • POST /api/games/{id}/next-round
    結算並開始下一回合
  • GET /api/games/{id}/analysis
    取得當前局面的蒙地卡羅分析建議

API 設計：系統與歷史

使用者認證 (Auth)

  • POST /api/auth/register - 註冊
  • POST /api/auth/login - 登入 (JWT Token)

歷史記錄與數據 (History)

  • GET /api/history/mistakes
    查詢個人的決策錯誤記錄
  • GET /api/history/sessions
    查詢過往的遊戲對局列表
  • GET /api/history/sessions/{id}/mistakes
    查詢特定對局的詳細檢討

核心特色詳解

五大功能深度解析

即時蒙地卡羅模擬

  • 即時進行數千次模擬
  • 計算每個動作的勝率、和局率、敗率
  • 標示最佳動作與期望值（EV）
EV 計算公式：
EV = (勝率 - 敗率) × 倍數

決策錯誤追蹤

  • 自動偵測玩家決策 vs 最佳策略
  • 記錄「失誤」操作
  • 回合結束後提供詳細檢討報告
  • 幫助玩家修正直覺偏誤

其他功能

  • 📊 牌靴視覺化：即時顯示剩餘牌卡分佈
  • 📝 歷史記錄：隨時回顧過往對局
  • 🎨 主題切換：深色/淺色模式

技術實現亮點

模擬演算法流程

  • 採取遞迴抽牌方式
  • 重複執行 10000 次，並記錄結果

資料庫設計

  • Users：帳號管理、授權
  • GameSessions：遊戲狀態存檔
  • Mistakes：學習歷程記錄

技術實現優勢

  1. 無狀態 API 設計：易於水平擴展
  2. 高效演算法：優化模擬速度，減少延遲
  3. 資料完整性：使用 ACID 資料庫交易
  4. 安全性：JWT 身份驗證

系統整體優勢

  • ⚡ 即時反饋：毫秒級建議
  • 📚 完整記錄：數據化學習成效
  • 🔬 科學方法：拒絕迷信，數據說話
  • 💎 使用者體驗：流暢的操作介面
